## 🚀 Tech Stack

- **Framework**: React 19 + Vite 8
- **Routing**: React Router 7 (Route-level code splitting with lazy loading)
- **Styling**: Pure Vanilla CSS design tokens & responsive utility suite
- **SEO**: Local Business Schema (JSON-LD), Canonical tags, Open Graph, Geo tags (Kakinada, AP)
- **Deployment**: Vercel configuration (`vercel.json`) with caching headers & SPA rewrites
